# Priyanshu Sharma — Portfolio

An immersive personal portfolio built with Next.js App Router, TypeScript, and modern web graphics techniques. Features dynamic GLSL shaders powered by Three.js, smooth scrolling via Lenis, magnetic UI components, and tailored animations built with GSAP and Framer Motion.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **3D & Shaders**: Three.js, React Three Fiber, GLSL
- **Animations**: GSAP, Framer Motion
- **Scrolling**: Lenis Smooth Scroll

## Getting Started

### Prerequisites

Ensure you have Node.js 18+ installed on your machine.

### Installation & Development

```bash
# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build & Production

```bash
# Run lint checks
npm run lint

# Build for production
npm run build

# Start production server
npm start
```
